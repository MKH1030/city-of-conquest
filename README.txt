# Kingdom Conquest — 2D browser version

This is a mobile-friendly HTML/CSS/JavaScript version of your Python strategy game. It can run on GitHub Pages.

## Upload using your phone
1. Download and unzip `kingdom_conquest_2d.zip`.
2. Open your GitHub repository in Chrome.
3. Tap **Add file → Upload files** and upload `index.html` to the repository root (the same level as your current GitHub Pages entry point).
4. Commit changes.
5. In **Settings → Pages**, make sure the correct branch (usually `main`) and folder (`/(root)`) are selected.
6. Open your GitHub Pages site and refresh.

If your repository already has an `index.html`, save a backup first or replace it with this one. This version uses emoji-based 2D visuals and needs no extra asset files or external libraries.
